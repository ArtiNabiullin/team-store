## About the Project

Team Store is a toy store web application built with TypeScript, Vite, and vanilla JavaScript.

Users can browse a product catalog, search for products by name, filter them by category and price range, sort products by price, and add items to a shopping cart.

The cart allows users to change product quantities, remove items, and view the total price. Cart data is stored in the browser's `localStorage`, so it remains available after refreshing the page.

The application includes an About page, a product catalog, and a shopping cart.
